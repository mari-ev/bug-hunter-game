# Bug Hunter

Портал для тестировщиков с игрой про охоту на багов.

## Что внутри
- Страница входа (тестировщик / гость)
- Главная страница (информация + рейтинг)
- Игра: мрачный тестировщик стреляет по жукам-багам

## Статус
- [x] Страница входа
- [x] Стили (тёмная тема, сетка, свечение)
- [ ] Главная страница
- [ ] Игра
- [ ] Рейтинг
- [ ] Автотесты

## Идеи
- Пиксельный персонаж в капюшоне
- Жуки-баги светятся в темноте
- Водяной пистолет (или что-то другое)
- Мрачная атмосфера, как в старых играх
